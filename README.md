# Rogue Trader: Insider 📈🕴️

## 🚀 Como fazer rodar?

Basta dar dois cliques no arquivo `index.html` para abrir e jogar direto no seu navegador. Simples assim!

*(Se precisar de um servidor local, use `npx serve .` ou `python3 -m http.server`)*

## 🤔 O que é esse jogo?

Um jogo de simulação onde você é um trader focado em "insider trading" (usar informações privilegiadas). Acumule dinheiro, libere novos contatos e domine o mercado de ações.
