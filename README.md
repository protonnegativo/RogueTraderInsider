# Rogue Trader: Insider 📈🕴️

## O que é esse jogo? 🤔
Um jogo de simulação onde você é um trader "diferenciado". O foco é atuar no mercado financeiro usando informações privilegiadas (insider trading)! Acumule dinheiro, libere novos contatos (insiders) e domine o mercado de ações.

## Como fazer rodar? 🚀

### Jeito Super Fácil:
Como o jogo é todo em HTML/JS padrão, basta dar **dois cliques no arquivo `index.html`** que ele vai abrir direto no seu navegador. Simples assim, já pode jogar!

### Jeito "Desenvolvedor" (Servidor Local):
Se preferir rodar com um servidorzinho local, abra o terminal na pasta do jogo e rode um destes comandos:
```bash
npx serve .
# ou
python3 -m http.server
```
Depois é só acessar o link que aparecer no terminal (geralmente `http://localhost:3000` ou `http://localhost:8000`). 🎉
